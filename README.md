SQL Data Warehouse & Analytics Project

📌 Overview

This project focuses on building a modern SQL Server Data Warehouse to consolidate sales data from two source systems (ERP and CRM), transform raw data into a clean and integrated data model, and deliver actionable business insights through SQL-based analytics.

The project is divided into two main phases:

1. Data Engineering: Design and build the Data Warehouse.
2. Data Analysis: Develop SQL-based analytics to support business intelligence and decision-making.

🎯 Project Objectives

The main objective is to provide business stakeholders with a centralized, reliable and user-friendly data foundation for analytical reporting and informed decision-making.

1. Data Warehouse Development (Data Engineering)

* Data Integration: Import data from ERP and CRM source systems provided as CSV files.
* Data Quality: Identify, cleanse and resolve data quality issues before analysis.
* Data Transformation: Standardize and transform data into a consistent structure.
* Data Modeling: Integrate both source systems into a unified, analytical data model.
* Scope: Focus exclusively on the latest available dataset. Historical data tracking and historization are not required.
* Documentation: Provide clear documentation of the data model for business stakeholders and analytics teams.

2. BI – Analytics & Reporting (Data Analysis)

Develop SQL-based analytics to generate business insights across three key areas:

* Customer Behavior: Understand customer characteristics and purchasing patterns.
* Product Performance: Evaluate product performance and sales contribution.
* Sales Trends: Analyze sales performance and identify relevant trends.

🛠️ Technology

* Database Platform: Microsoft SQL Server
* Query Language: SQL
* Source Data: ERP and CRM (CSV files)

📊 Expected Outcome

A centralized SQL Server Data Warehouse that integrates ERP and CRM sales data into a reliable analytical data model, providing the foundation for customer, product and sales analytics.

The final solution aims to transform raw operational data into meaningful business insights that support strategic decision-making.
